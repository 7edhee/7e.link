# 7e.link

A media-rich single-page web experiment for presenting local video content through a lightweight HTML and CSS interface.

## Run locally

Open `index.html` in a modern browser, or serve the directory with any local static HTTP server. The page uses the media files stored in this repository.

## Notes

This is a visual experiment. Large media assets are intentionally kept separate from the page structure so the presentation can be iterated independently.
